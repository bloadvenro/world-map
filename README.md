# Атлас флагов

Полноэкранная говорящая карта мира с флагами и русскими названиями 195 стран. [Открыть карту](https://bloadvenro.github.io/world-map/)

Общие границы стран обозначены белой линией с тонким тёмным кантом. Коснитесь страны, чтобы услышать название и увидеть её флаг целиком. Одним пальцем можно листать карту по кругу, двумя — менять масштаб от 1× до 2×. Маленькие страны обозначены точками. Число в метке показывает, сколько стран можно выбрать рядом. На компьютере работают перетаскивание мышью и зум колёсиком. Для управления с клавиатуры перейдите к карте клавишей Tab и используйте стрелки, плюс и минус. Следующее нажатие Tab открывает выбор страны по названию.

## Установка и работа без сети

Откройте карту с интернетом и дождитесь сообщения «Карта доступна без интернета». Оно появляется после сохранения контуров, флагов и всех 195 записей. В браузере на Android выберите установку приложения. На iPhone откройте карту в Safari и выберите «Поделиться» → «На экран “Домой”». При первом запуске с домашнего экрана дождитесь готовности офлайн в установленном приложении.

## Локальный запуск

Для разработки используются Node.js 22 и npm.

```sh
npm ci
npm run dev
```

`npm run build` сверяет каталог с геометрией и ресурсами, проверяет TypeScript и создаёт статический сайт в `dist/`. Сервис-воркер создаётся для production-сборки. Локально её можно открыть командой `npm run preview`.

Для браузерных тестов выполните `npx playwright install chromium`, затем `npm run build` и `npm test`. С установленным Google Chrome можно использовать `ATLAS_CHROME_CHANNEL=chrome npm test`. Сценарии проверяют выбор стран и звук, жесты, разворот экрана и холодный запуск без сети.

## Данные

Карта использует стандартные границы Natural Earth 5.1.1, соответствующие фактическому контролю на момент выпуска атласа. В каталоге 195 стран. Англия входит в Великобританию, остальные отдельные территории источника показаны нейтральным цветом. Контуры можно воспроизвести командой `python3 scripts/prepare-map.py --flags public/flags --output public/world.json`. [Natural Earth](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/)

Русские названия, флаги и записи взяты из проекта Country Balls. Флаги подготовлены из flag-icons, записи синтезированы голосом Piper Denis, шрифт интерфейса — Nunito. [Сведения о ресурсах](public/licenses/)
